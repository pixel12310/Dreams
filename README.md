# 褪色 · FADING

**《一个人的世界，是从什么时候开始褪色的？》**：一部 60 秒的程序化动画短片。

- **成片**：[`output/fading_1080p.mp4`](output/fading_1080p.mp4)（1920×1080，30fps，60 秒，原创配乐与音效）
- **实时版**：[`film/index.html`](film/index.html)（浏览器打开即可播放，WebGL2，空格暂停，← → 快退快进）

画面里没有一张图片素材，每一帧都由代码实时绘制；配乐和音效也全部由程序合成。

## 创意

整部片子是一个**一镜到底**的长镜头：一个人从 7 岁一直走到 35 岁，镜头始终跟着他，没有剪辑。他边走边长大，世界也在他身边一点一点变化。

颜色不是一下子消失的，而是**按色相一条一条被抽走**：

| 失去的颜色 | 发生了什么 |
|---|---|
| 🔴 红 | 七岁，风筝断了线 |
| 🟡 黄 | 十八岁离家，门口那盏灯 |
| 🟢 绿 | 二十六岁，城市里的树开始落叶 |
| 🔵 蓝 | 三十五岁，低头看手机，很久没有抬头看过天空 |

所以片子的回答是：**世界不是一下子褪色的，是我们一点一点，忘了抬头。**

结尾，全灰的雨夜里，童年那只红风筝从天上落下来。它是画面里唯一的颜色，世界的时间也随之慢下来。他终于抬起头，伸手接住风筝线，颜色便以风筝为圆心，像水墨一样晕开，回到整个世界。所有的雨伞、树、窗灯，原来一直都在。雨停了，彩虹出来，风筝重新飞上蓝天。

> 抬头看看吧，今天的天空很蓝。

## 技术要点

**画面（`film/film.js`）**
- **整片是时间的纯函数**：`FILM.renderAt(t)` 对任意时刻 t 都能画出确定的一帧，所以可以拖动进度条随意跳转，也能离线逐帧导出。所有粒子（雨、落叶、萤火、光点）都是无状态的解析函数，不依赖上一帧。
- **程序化角色骨骼**：两段 IK 驱动腿和手臂；步态相位由相机位移对步幅积分得到，所以**脚始终踩实地面、不打滑**。奔跑与行走两种步态可以混合，站立时有呼吸起伏。身高、头身比、四肢粗细、驼背程度、头部俯仰都随年龄连续变化（7 → 18 → 26 → 35 岁）。
- **十余层视差**：近景按透视统一缩放（深度 p 同时决定位置、大小和地平线高度）；前景元素带景深虚化。远景层改为跟随时间而不是空间演化，所以城市是从地平线“长”出来的。
- **WebGL 后期调色**：着色器把画面转换到 HSV，**红、黄、绿、蓝四个色相通道各自独立地去饱和**；再用 fbm 噪声做阈值，让褪色像水彩被晒褪一样一块一块地发生，而不是均匀变灰。结尾的色彩恢复是一道带噪声扰动边缘的径向波前。
- 湿地面实时倒影（带涟漪扰动）、辉光、暗角、色差、胶片颗粒；延时摄影段落用多重曝光拖影表现人群和车流。

**声音（`tools/compose_score.py`）**
- 用 numpy 从零合成：钢琴（非谐泛音、双弦拍频、两段衰减、击弦噪声、制音）、八音盒、铃、弦乐垫，再经卷积混响。
- 环境声包括风、鸟鸣、蟋蟀、城市底噪、过路车、雨、雨滴、远雷，此外还有风筝扑簌声、断线声、心跳和延时摄影的呼啸。
- **脚步声与画面逐帧同步**：渲染器先从动画里导出每一次脚掌触地的时刻和地面材质（草地、石子路、柏油路、湿地面），合成器再据此生成脚步。
- 音色随剧情变化：颜色每被抽走一层，音乐就更暗、更湿；颜色回来的瞬间，滤波器整个打开。

## 运行与重新导出

需要 Node 18+（带 Playwright / Chromium）、ffmpeg，以及 Python 3（numpy、scipy）。

```bash
# 在浏览器里实时观看
npx serve film        # 然后打开 http://localhost:3000 ；也可以直接双击 film/index.html

# 导出：画音同步的事件 → 配乐 → 逐帧渲染并合成视频
node tools/render.mjs events build/events.json
python3 tools/compose_score.py build/events.json build/soundtrack.wav
node tools/render.mjs video output/fading_1080p.mp4 --audio build/soundtrack.wav

# 单帧预览
node tools/render.mjs stills 7,18.6,44,52.5 stills/
```

`film/fonts.js` 是按片中用到的字裁剪出来的 Noto Serif SC 子集（SIL OFL 1.1），由 `tools/build_fonts.py` 生成；改了文案之后重新运行它即可。

## 文件结构

```
film/
  index.html        播放器（实时版）
  film.js           动画引擎：时间线、场景、角色骨骼、粒子、WebGL 调色
  fonts.js          内嵌字体子集
  soundtrack.mp3    配乐（实时版使用）
tools/
  render.mjs        无头 Chromium 逐帧渲染 → ffmpeg；导出画音同步事件
  compose_score.py  配乐与音效合成
  build_fonts.py    字体子集生成
output/
  fading_1080p.mp4  成片
```
