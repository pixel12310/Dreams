# 想你了 · MISS YOU

> 对方说一句想你了，可你第一反应不是开心，而是心里一阵说不上来的慌。

镜头表《想你了》的 15 个镜头被逐个做成动画，共 44 秒。时间线严格按镜头表的顺序和估计时长排列，口播以字幕形式出现；片尾加了 3.6 秒的片名。

## 怎么拍的

| S02 | 0:03.3 | 她的侧脸，只被下方的屏幕光照亮，眼睛里映着一小块屏幕。她眨了一下眼，嘴角始终没动 | 一个低音钢琴单音 |

| 片名 | 0:40.4 | 想你了 · 越被认真对待，越想后退 | 一个悬着、没有解决的和弦 |

导演备注里的几条在片子里都有对应：

- **构图即潜台词**：S06 两人挨着坐 → S08 隔着桌子对坐 → S15 各占桌子一头。S06 和 S15 共用一套场景代码和机位，只换了光线和人物的位置。
- **意义物件**：蓝边小鱼碗在 S07 是“一起吃饭很自在”，到 S13 变成“吃饭声让人不舒服”。
- **连贯性**：餐桌戏里她始终在画左、朝右，他在画右、朝左，机位不越轴。过去用暖色正午阳光加柔光和光晕，现在用偏绿的冷色日光灯。
- **主观声音**：他的说话声和咀嚼声都是她听到的样子，不是真实的音量。
- **三次法则**：语气 → 回消息速度 → 吃饭声，一件比一件小，声音处理一次比一次夸张，到第三件只剩那一个声音。

## 技术要点

- **代码结构**（`missyou/`）：`core.js` 管时间线、相机、景深图层、光照图和 WebGL 调色；`people.js` 是两个角色；`phone.js` 是手机和聊天界面；`shots-night.js` 是 S01–S05；`shots-diner.js` 是 S06–S15 和片名。
- **整片是时间的纯函数**：`FILM.renderAt(t)` 对任意时刻都能画出确定的一帧。接口和《褪色》相同，所以导出工具可以共用。
- **角色**：侧脸用手工调出的轮廓，支持眨眼、视线、下颌转动（用于咀嚼）和转头。正脸和四分之三侧脸是一个由水平截面组成的头部模型，绕竖直轴旋转后投影出来；眼睛、眼睑、眉毛、鼻子、嘴唇都是三维点。眯眼、皱眉、笑眼、说话的口型都是连续参数。
- **光**：先把场景画成全亮的样子，再乘一张光照图（环境光 + 手机屏幕 + 窗外冷光），所以 S05 手机一扣下，整个房间会真的暗下去。角色身上另外画了主光渐变和轮廓光。
- **景深**：每个景深层先画到离屏画布，再模糊后合成。S03 的焦点转移就是让两层的模糊量交叉过渡。
- **调色**（WebGL）：线性空间里做曝光和白平衡，加上胶片式高光肩部、分离色调、柔光、泛光、红色光晕、色差、暗角和颗粒。每个镜头有自己的一套参数，S06 硬切时的曝光过冲也在这里做。
- **声音**（`tools/compose_missyou.py`）：钢琴、铺底、人声群杂、说话声（锯齿波声源加共振峰滤波）、笑声、咀嚼声、按键声、提示音、心跳，全部用 numpy 合成。画面导出 101 个事件（每次按键、每个音节、每次咀嚼），音效按这些事件逐个对位。

## 运行与重新导出

```bash
# 实时观看
npx serve missyou     # 也可以直接打开 missyou/index.html

# 导出：画音同步事件 → 配乐 → 逐帧渲染并合成视频
node tools/render.mjs events build/missyou_events.json --film missyou
python3 tools/compose_missyou.py build/missyou_events.json build/missyou.wav
node tools/render.mjs video output/missyou_1080p.mp4 --film missyou --audio build/missyou.wav

# 单帧预览；改了文案后重建字体子集（Noto Serif SC + Noto Sans SC）
node tools/render.mjs stills 2,10,16,33,38 stills/ --film missyou
python3 tools/build_fonts.py missyou --sans
```

# 褪色 · FADING

**《一个人的世界，是从什么时候开始褪色的？》**：一部 60 秒的程序化动画短片。

- **成片**：[`output/fading_1080p.mp4`](output/fading_1080p.mp4)（1920×1080，30fps，60 秒，原创配乐与音效）

## 创意

整部片子是一个**一镜到底**的长镜头：一个人从 7 岁一直走到 35 岁，镜头始终跟着他，没有剪辑。他边走边长大，世界也在他身边一点一点变化。

颜色不是一下子消失的，而是**按色相一条一条被抽走**：

| 失去的颜色 | 发生了什么 |
|---|---|
| 🔴 红 | 七岁，风筝断了线 |
| 🟡 黄 | 十八岁离家，门口那盏灯 |
| 🟢 绿 | 二十六岁，城市里的树开始落叶 |
| 🔵 蓝 | 三十五岁，低头看手机，很久没有抬头看过天空 |

所以片子的回答是：**世界不是一下子褪色的，是我们一点一点，忘了抬头。**

结尾，全灰的雨夜里，童年那只红风筝从天上落下来。它是画面里唯一的颜色，世界的时间也随之慢下来。他终于抬起头，伸手接住风筝线，颜色便以风筝为圆心，像水墨一样晕开，回到整个世界。所有的雨伞、树、窗灯，原来一直都在。雨停了，彩虹出来，风筝重新飞上蓝天。

> 抬头看看吧，今天的天空很蓝。

## 技术要点

**画面（`film/film.js`）**
- **整片是时间的纯函数**：`FILM.renderAt(t)` 对任意时刻 t 都能画出确定的一帧，所以可以拖动进度条随意跳转，也能离线逐帧导出。所有粒子（雨、落叶、萤火、光点）都是无状态的解析函数，不依赖上一帧。
- **程序化角色骨骼**：两段 IK 驱动腿和手臂；步态相位由相机位移对步幅积分得到，所以**脚始终踩实地面、不打滑**。奔跑与行走两种步态可以混合，站立时有呼吸起伏。身高、头身比、四肢粗细、驼背程度、头部俯仰都随年龄连续变化（7 → 18 → 26 → 35 岁）。
- **十余层视差**：近景按透视统一缩放（深度 p 同时决定位置、大小和地平线高度）；前景元素带景深虚化。远景层改为跟随时间而不是空间演化，所以城市是从地平线“长”出来的。
- **WebGL 后期调色**：着色器把画面转换到 HSV，**红、黄、绿、蓝四个色相通道各自独立地去饱和**；再用 fbm 噪声做阈值，让褪色像水彩被晒褪一样一块一块地发生，而不是均匀变灰。结尾的色彩恢复是一道带噪声扰动边缘的径向波前。
- 湿地面实时倒影（带涟漪扰动）、辉光、暗角、色差、胶片颗粒；延时摄影段落用多重曝光拖影表现人群和车流。

**声音（`tools/compose_score.py`）**
- 用 numpy 从零合成：钢琴（非谐泛音、双弦拍频、两段衰减、击弦噪声、制音）、八音盒、铃、弦乐垫，再经卷积混响。
- 环境声包括风、鸟鸣、蟋蟀、城市底噪、过路车、雨、雨滴、远雷，此外还有风筝扑簌声、断线声、心跳和延时摄影的呼啸。
- **脚步声与画面逐帧同步**：渲染器先从动画里导出每一次脚掌触地的时刻和地面材质（草地、石子路、柏油路、湿地面），合成器再据此生成脚步。
- 音色随剧情变化：颜色每被抽走一层，音乐就更暗、更湿；颜色回来的瞬间，滤波器整个打开。

## 运行与重新导出

需要 Node 18+（带 Playwright / Chromium）、ffmpeg，以及 Python 3（numpy、scipy）。

```bash
# 在浏览器里实时观看
npx serve film        # 然后打开 http://localhost:3000 ；也可以直接双击 film/index.html

# 导出：画音同步的事件 → 配乐 → 逐帧渲染并合成视频
node tools/render.mjs events build/events.json
python3 tools/compose_score.py build/events.json build/soundtrack.wav
node tools/render.mjs video output/fading_1080p.mp4 --audio build/soundtrack.wav

# 单帧预览
node tools/render.mjs stills 7,18.6,44,52.5 stills/
```

`film/fonts.js` 是按片中用到的字裁剪出来的 Noto Serif SC 子集（SIL OFL 1.1），由 `tools/build_fonts.py` 生成；改了文案之后重新运行它即可。

## 文件结构

```
film/
  index.html        播放器（实时版）
  film.js           动画引擎：时间线、场景、角色骨骼、粒子、WebGL 调色
  fonts.js          内嵌字体子集
  soundtrack.mp3    配乐（实时版使用）
tools/
  render.mjs        无头 Chromium 逐帧渲染 → ffmpeg；导出画音同步事件
  compose_score.py  配乐与音效合成
  build_fonts.py    字体子集生成
output/
  fading_1080p.mp4  成片
```
