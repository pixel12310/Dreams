# 初见 · FIRST SIGHT

**《一个人的世界，是从什么时候开始褪色的？》**：一部 95 秒的程序化水墨动画短片。

- **成片**：[`first-sight_1080p.mp4`](first-sight_1080p.mp4)（1920×1080，30fps，原创配乐与音效）
- **实时版**：[`index.html`](index.html)（浏览器打开即可播放，WebGL2；空格暂停，← → 快退快进）

没有一张图片素材。宣纸、水彩、毛笔字、人物、配乐和音效，全部由代码逐帧生成。

---

## 片子给出的回答

> **从我只认得它们的名字，却不再看见它们的那天起。**

小时候，每样东西都是第一次见。后来我们学会了它们的名字，这是长大，也是一件礼物。可再后来，我们只剩下名字：看见太阳，脑子里只闪过一个"日"字，就不再抬头。

汉字本身就是这个故事。"日"原本是一个画出来的太阳 ⊙，"山"是三座山峰，"木"是一棵有枝有根的树，"人"是一个侧身走路的人。从象形到符号，就是一样东西慢慢褪成它的名字。片子把这个过程倒过来又正过来演了一遍：东西变成字，手写的字变成印刷体，印刷体掉进格子，格子里只剩下"日、日、日……"，**日复一日**。

最后让世界回来的，是一个孩子的问题：

> 「爸爸，太阳是什么颜色的？」

他当然知道答案，"红"。可那个字是灰的。于是他抬起头，**真的去看了一眼**。

> 今天的太阳，也是第一次升起。

## 技术要点

**字与物（`js/glyphs.js`）**
- 片中十个象形字（日 山 木 水 雨 人 高 车 门 云）都是逐笔写成的楷书笔画数据，包括点、横、竖、撇、捺、折、钩和笔顺。
- 每个字都配一份**笔画数相同的实物草图**：⊙ 对应"日"，三座山峰对应"山"，有枝有根的树对应"木"……变形时按目标字形的弧长、在折角处对齐采样，所以太阳会先被勾成草图，再拉直成"日"，最后换成宋体印刷字，正好就是汉字从象形到符号的演变。

**毛笔（`js/brush.js`）**
- Catmull-Rom 中轴线（遇折角断开）加逐点笔宽，生成笔画轮廓：有斜切的起笔、顿笔、圆转的折角、手的微颤，笔锋收尾处还有枯笔飞白。
- 笔画可以按长度"写"出来，题目、描红本、"人"字都是一笔笔写出来的。

**宣纸与水彩（`js/gfx.js`）**
- 每一帧画在六层画布上（颜料、墨、光、蜡笔、文字、"生命"遮罩），再由一个 WebGL2 着色器铺到程序生成的宣纸上。效果包括：颜料在边缘沉积（Bousseau 的颜料密度模型）、颗粒与湍流、墨渗进纸纤维、线条以每秒 12 次轻微抖动（boil）、辉光、颗粒和暗角。
- 整部片子的主题由两个旋钮控制：**sat**（颜色）和 **tex**（手工感：纸纹、渗墨、抖动）。死去的世界不只是变灰，而是变**平**：没有纸纹，没有手的痕迹，像一页打印件。
- 蜡笔层只停在纸的凸起处，并且永远不会被褪色，所以灰色世界里的那抹红始终是红的。女儿身上有一张"生命遮罩"，在灰色的房间里她始终有颜色。
- 颜色回归是一道带噪声扰动边缘的圆形波前。它同时驱动着色器和每一样东西的变形参数：波前经过哪里，哪里的字才变回东西。

**人物（`js/figures.js`）**
- 一套绘本风格的骨骼，负责片中所有人：孩子、妈妈、年轻人（后来的父亲）、女儿、路人，可以是侧面、正面或背面，表现为细墨线配略微错位的水彩填色。
- 每个人先画在自己的离屏画布里，前面的手臂会遮住身后的轮廓线；然后整个人作为一层颜料覆在画面上，挡住他身后的线条。
- 走路相位锁定在行走距离上，脚不打滑；两段 IK 让女儿的手握着蜡笔，一路沿着太阳、光线和涂色的路径移动。

**城市（`js/city.js`）**
- 每一天都比前一天短 25%。天色、窗灯、车流和季节都由同一张"日程表"驱动。之后颜色褪去、物体变成字、手写变成印刷，字再掉进 32×18 的格子，"日"从太阳所在的那一格向外一格格填满。

**声音（`../tools/score_first_sight.py`）**
- 全部用 numpy 合成。古筝用加法合成钢弦：近琴码的拨弦位置、非谐泛音、两段衰减和琴身共鸣，再加上滑音、按音、揉弦、泛音和刮奏。箫有气声、延迟出现的颤音和滑入。此外还有钢琴、弦乐垫，以及一台会"磨损"的闹钟。
- 全片只有一个动机：四个音的问句 A–B–D–E。它在每个早晨重复，一天比一天快、一天比一天旧：从古筝到电钢琴，到 8-bit 蜂鸣，最后只剩一声嘀嗒，直到父亲抬头的那一刻，它才第一次落回主音 D。
- 画面里的毛笔字、描红、蜡笔、门、跳上桌子、计数器翻页和盖印，时刻都由渲染器导出，声音因此逐帧对齐。

## 运行与重新导出

需要 Node 18+（带 Playwright / Chromium）、ffmpeg，以及 Python 3（numpy、scipy）。

```bash
# 实时观看
npx serve first-sight      # 然后打开 http://localhost:3000

# 导出：画音同步的事件 → 配乐 → 逐帧渲染并合成视频
node tools/render.mjs events build/fs_events.json --film first-sight
python3 tools/score_first_sight.py build/fs_events.json build/fs_score.wav
node tools/render.mjs video first-sight/first-sight_1080p.mp4 --film first-sight --audio build/fs_score.wav

# 单帧预览
node tools/render.mjs stills 26.6,51.6,67.2,85.2 stills/ --film first-sight
```

`fonts.js` 是按片中用到的字裁剪出来的 Noto Serif SC 和马善政楷书（Ma Shan Zheng）子集，两者都采用 SIL OFL 1.1 许可，由 `python3 tools/build_fonts.py first-sight` 生成。
